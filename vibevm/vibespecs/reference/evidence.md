# Dated evidence and public sources

This is package **1.0.2**'s qualitative evidence note. Public provider pages,
release records and independent benchmark pages were checked on **2026-10-21**.
The general recommendation and assignment profiles retain their preceding
meaning. This note records no new model evaluation or account measurement.
Consumers assess freshness for a new selection under their own authority;
a later source change does not mutate an admitted task.

## Why the profile choices remain

Artificial Analysis's [Codex comparison](https://artificialanalysis.ai/agents/coding-agents/comparisons/codex-vs-muse-code)
still reports Coding Agent Index **v1.5** results for explicit model/effort
combinations in the **Codex** harness. The checked Sol/xhigh result remains
stronger on that coding composite than Sol/max. Sol/max is higher on the
distinct Intelligence Index **v4.3.2** in the
[Sol release comparison](https://artificialanalysis.ai/models/releases/gpt-6-1-sol).
This supports retaining Sol/xhigh as the complex-work starting point and
requiring task-specific evidence before max escalation. It does not prove that
one setting wins every task or that the difference is statistically significant.

Astra/max remains an exceptional quality escalation, with a larger measured
API cost and longer agent time in the checked coding comparison. The provider's
[model guidance](https://learn.chatgpt.com/docs/models) positions Astra for the
hardest workflows, Sol for repeated complex work, and Luna for clear repeatable
tasks. Our precise effort and assignment choices are project judgment;
provider guidance does not benchmark each row of our assignment matrix.
Luna/high, Terra/max and several other efforts still lack like-for-like entries
in the checked Codex comparison table. Results at max do not measure high.

## Read the methodology with the result

The [Coding Agent methodology](https://artificialanalysis.ai/methodology/coding-agents-benchmarking)
combines DeepSWE **v1.1**, Terminal-Bench **4.0** and SWE-Atlas-QnA. Read their
breakdowns together: a composite can hide weaknesses in repository changes,
terminal work or repository Q&A. Do not numerically mix v1.5 with v1.4.
Benchmark API-priced cost differs from Codex subscription usage; recorded agent
time excludes environment startup, verification and judging. Some displayed
costs and rounded token totals changed since the preceding refresh while the
tracked OpenAI coding scores stayed the same. This alone establishes no change
in model capability or consumer cost.

The [Intelligence methodology](https://artificialanalysis.ai/methodology/intelligence-benchmarking)
still identifies **v4.3.2**, released in **September 2026**, without an exact day.
It measures a different task mix, grading setup and Terminal-Bench run from the
Codex coding index. Its pairwise ratings depend on judges and rating anchors;
displayed changes within a version need not be model improvements. Read current
[Intelligence comparisons](https://artificialanalysis.ai/leaderboards/models)
as external context, with each model's effort and fallback configuration.
They neither establish Codex access nor fill missing coding-agent evidence.

## Model, client and lifecycle evidence

The checked [Codex models page](https://learn.chatgpt.com/docs/models) retains
Sol 6.1, Astra, Sol 6 and Luna 6, with GPT-5.6 Sol, Terra and Luna available
during rollout. Access depends on plan, client, sign-in method, rollout and
workspace controls. Sol 6.1's [API specification](https://developers.openai.com/api/docs/models/gpt-6.1-sol)
supports low, medium, high, xhigh and max, defaults to medium, and excludes
none/minimal. API specifications do not prove an account's Codex controls.

Public release records confirm Sol 6.1 in the bundled CLI catalog at
[0.159.1](https://github.com/openai/codex/releases/tag/rust-v0.159.1), dated
2026-09-29, and Sol/Luna 6 picker support at
[0.156.1](https://github.com/openai/codex/releases/tag/rust-v0.156.1), dated
2026-09-23. These are the earliest publicly confirmed catalog releases tracked
here; they do not prove older clients cannot submit an explicit model ID.
Astra's historical CLI minimum remains unconfirmed and is withheld.

The latest stable release checked was
[Codex CLI 0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0),
published 2026-10-15. Its notes describe live configuration controls, immediate
steering/interruption, parallel read-only tools and restored permissions on
resume. Release notes are not proof of an installed build or a consumer rollout.
Daybreak eligibility mentioned by that release remains subject to separate
[Trusted Access](https://learn.chatgpt.com/docs/cyber-safety) approval; it creates
no general cyber profile recommendation or authorization.

The [2026-10-14 changelog](https://learn.chatgpt.com/docs/changelog) says GPT-5.5
retired from Codex with ChatGPT sign-in at **19:00 UTC** that day. The API and
API-key-authenticated Codex sessions are unaffected. This is an effective
provider lifecycle notice, not a live removal test or authority to substitute
an admitted consumer profile.

## Pricing, caching and speed

The checked [Codex pricing](https://learn.chatgpt.com/docs/pricing),
[API pricing](https://developers.openai.com/api/docs/pricing) and
[speed controls](https://learn.chatgpt.com/docs/agent-configuration/speed)
retain the distinction between token USD rates, Codex credit rates and included
subscription allowance. API cost does not convert into weekly quota. Standard
remains this guidance's default speed unless the user chooses another speed.
Ultra delegation and Ultrafast inference are separate controls.

On 2026-10-20 the [API changelog](https://developers.openai.com/api/docs/changelog)
announced a 12-hour caching option. The
[cache guide](https://developers.openai.com/api/docs/guides/prompt-caching)
distinguishes its higher write rate from the default 30-minute lifetime and
cached reads. This API feature is not a Codex allowance change. Sol Ultrafast's
2026-10-08 availability remains plan/workspace-dependent and supports US and
European inference residency. The same API changelog records Ultrafast and
bundled Artifact SDK/document skills for the Agents API on 2026-10-16. These
service features do not establish Codex access or change the guidance profiles.
This package exports no rate card or quota data.
